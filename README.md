# Engenharia de Software

Resumos das aulas de Engenharia de Software, feitos a partir do material do professor. Cada aula tem a sua pasta.

Professor: Herysson R. Figueiredo · [repositório da disciplina](https://github.com/Herysson/Engenharia-de-Software)

Cada pasta `aulaXX/` tem um `README.md` com o resumo e um link para o material original. As aulas práticas também têm um `exercicios.md`, com as soluções. Os resumos têm dois formatos:

- **Exercícios**: conceitos em tabelas curtas, exemplos resolvidos e exercícios com solução
- **Canvas**: blocos curtos, comparações e esquemas, para as aulas mais teóricas

## Conteúdo

- Princípios da Engenharia de Software e processo de software
- Modelos de processo, desenvolvimento ágil e RUP
- Paradigmas de programação e orientação a objetos
- Engenharia de requisitos
- UML: atividades, estados, casos de uso, classes, domínio e objetos
- Qualidade de software

## Como ver os diagramas

Os diagramas estão em [Mermaid](https://mermaid.js.org/), que o GitHub desenha direto na página. Os diagramas feitos no Astah ficam na pasta `img/` de cada aula.
